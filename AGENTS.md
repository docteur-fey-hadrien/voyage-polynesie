# RÈGLE PERMANENTE DU PROJET VOYAGE POLYNÉSIE

À chaque interaction de l'assistant (agent IA) dans ce projet :

1. **Tenue obligatoire du Journal de Bord (`JOURNAL_DE_BORD.md`)** :
   - À chaque nouvelle requête, recherche, analyse ou décision, consigner systématiquement une entrée datée dans `JOURNAL_DE_BORD.md`.
   - Mentionner : la date/heure de l'interaction, les recherches effectuées (emails consultés, sources, requêtes), les informations découvertes, les décisions prises et les prochaines étapes.

2. **Mise à jour des dossiers thématiques (`DOSSIER_VOYAGE/`)** :
   - Dès qu'une nouvelle information sur les vols, les hébergements, les activités ou les paiements est trouvée, actualiser immédiatement les fichiers correspondants dans le dossier `DOSSIER_VOYAGE/` :
     - `PROGRAMME_DETAILLE.md` (itinéraire jour par jour, hôtels, vols, activités)
     - `AJUSTEMENTS_ET_ECHANGES.md` (modifications validées avec l'agence Tribu d'Explorateurs et échanges avec Aurélie)
     - `CONTACTS_ET_INFOS_PRATIQUES.md` (coordonnées d'urgence, franchises bagages, références dossiers)
     - `POINTS_EN_SUSPENS.md` (questions à clarifier, formalités en attente)

3. **Préservation des pièces justificatives et documents** :
   - Tous les documents PDF ou fichiers reçus doivent être conservés et référencés clairement avec leur chemin relatif.

4. **Règle absolue de Sécurité & Protection de la Vie Privée (Site Public GitHub Pages)** :
   - **INTERDICTION STRICTE** de publier sur le site web ou dans tout fichier suivi par Git public :
     - Les numéros de dossier / codes PNR de réservation aérienne ou hôtelière (ex: `Y88YII`, références devis).
     - Le nom de famille et les prénoms de la famille (Hadrien, Aurélie, Louison, Manoé, Moana). Toujours utiliser des alias anonymes et chaleureux (*« Papa & Maman »*, *« les jumeaux »*, *« notre bébé »*, *« toute la tribu »*).
     - Les adresses postales personnelles, communes de résidence spécifiques, numéros de téléphone privés, adresses emails personnelles, ou données médicales / ordonnances.
     - Les documents d'identité, numéros de passeport ou numéros de dossier ESTA.
   - En cas de doute sur une information à intégrer sur le site web public, **TOUJOURS demander l'accord explicite préalable de l'utilisateur**.
